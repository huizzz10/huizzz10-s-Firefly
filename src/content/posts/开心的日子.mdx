# 序 1.11

开始嘛很简单，就是和她们一起做能扎气球的小车，比赛嘛也很简单，就是让小车在规定时间巡线后内扎到更多的指定颜色气球  
结果这是这几天噩梦的开始  
话说回来，刚报名那几天确实在幻想能拿奖，不知道是为什么，反正把牛吹出去了  
现在想想挺搞笑的  
不经过考虑就答应别人，我确实该改一改  

# 破 2.22

事情的一切都进展很快，虽然我们很懒，从9月底才开始好好准备  
但现在有DeepSeek的我是无敌的（真的假的？）  
写的这段时间，我也是吃上了不少苦头，虽然我不想承认，但我确实是个菜鸟  
而且我过分依赖vibe coding，所以没有做好OpenMV和Arduino的结合  

不过也是因为这样，我和她们有时间摆龙门阵  
在这个时间段，可以让我了解女生的想法，感觉没那么害怕女生了  
还有就是可以通过Agent的方式编程，许愿就能实现，让我这个爱好者感到无限的快乐  

# Q 3.33

好了，到了最难受的部分了  
为什么就调不出来OpenMV和Arduino的强强联合呢？  
巡线也是老是出问题，走着走着就掉线了  
时间一天一天的近了，压力越来越大，最后也勉勉强强做出了一个，结果莫名其妙挂了  
各种方案也试了，最后还是没调出来  

对待这个情况，选择耍起  
钱也不报销，真没法了，那为什么不耍起  
但是总感觉心里不得劲啊  

# 终 3.0+1.11

好吧，到了最后，还是各种意外出现，主要是抱着耍起的心态去比赛  
前一天晚上还正常，第二天早上就各种意外  
但是呢，比赛还是过了巡线这一块，我觉得已经做得很好了  
其他三位也觉得很开心，虽然没拿奖，但我们都很开心  
烧烤，唱K，吃饭，玩游戏等，这是我第一次离女生那么近  
唉，可惜了，以后没那么多机会了  

# 后言

这次比赛让我明白我的一个弱点——太容易相信别人从而给出承诺
